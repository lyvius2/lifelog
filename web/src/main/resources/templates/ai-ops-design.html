Spring AI · Operations Automation

Spring AI Ops

Grafana Alerting과 GitHub Webhook을 수신하여 LLM(OpenAI / Anthropic)으로 장애를 분석하고 코드를 리뷰하는 AI 기반 운영 자동화 도구입니다. 분석 결과는 WebSocket을 통해 실시간 대시보드에 전달됩니다.

동적 LLM 전환

Hot-Swap

UI에서 OpenAI ↔ Anthropic을 재시작 없이 전환 가능합니다. AutoConfiguration을 비활성화하고 직접 모델을 관리합니다.

Zero-RDB 설계

Redis Only

관계형 DB 없이 Redis를 유일한 저장소로 사용합니다. 로컬 개발 시 Embedded Redis가 자동 기동됩니다.

Redis Embedded

Virtual Thread

Async

Java 21 CompletableFuture

시스템 아키텍처

Architecture

외부 시스템(Grafana, GitHub)으로부터 Webhook을 수신하고, Facade가 Loki/GitHub API 조회와 LLM 분석을 오케스트레이션합니다. 결과는 Redis에 저장되고 WebSocket으로 브라우저에 Push됩니다.

Controller

HTTP 요청 수신 및 DTO 반환. 비즈니스 로직 없음.

Facade (@Facade)

여러 Service를 조합하여 하나의 유즈케이스를 처리. 트랜잭션 경계.

Service

단일 책임 비즈니스 로직 및 Redis 데이터 관리.

Connector (Feign)

Loki API, GitHub API와 통신하는 OpenFeign 클라이언트.
